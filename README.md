# caddy-http-acme

A minimal Caddy DNS provider for ACME DNS-01 services which expose an HTTP API.

The provider intentionally has a tiny scope: when Caddy asks it to publish a TXT
challenge, it expands its placeholders in `endpoint` and `params`, then sends one
HTTP request. Cleanup is a no-op because services such as myaddr.tools
automatically expire their ACME TXT values.

## Example: myaddr.tools

```caddyfile
yourname.myaddr.tools {
    tls {
        dns http_acme {
            endpoint https://myaddr.tools/update
            method POST
            body json

            params {
                key {env.MYADDR_KEY}
                acme_challenge {http_acme.challenge}
            }
            
            result {
                success_code 200 # or "2xx" for any 2xx code
                success_body "OK" # substring match; see success_body_regex
            }
        }
    }
}
```

## Placeholders

The module provides these placeholders:

| Placeholder | Value | Example |
| --- | --- | --- |
| `{http_acme.challenge}` | TXT value generated by ACME | `gfj9Xq...` |
| `{http_acme.zone}` | challenged zone, without trailing dot | `example.com` |
| `{http_acme.fqdn}` | full name of the TXT record, without trailing dot | `_acme-challenge.example.com` |

The placeholders work in `params` values and in `endpoint`, in Caddyfile and in
JSON config. Normal Caddy placeholders such as `{env.MYADDR_KEY}` also work:
Caddy resolves them when the config loads. The `http_acme.*` placeholders
resolve when Caddy performs the challenge. Unknown placeholders stay literal.

> Breaking change: the old `{challenge}` and `{domain}` tokens are no longer
> replaced. Use `{http_acme.challenge}` and `{http_acme.zone}`.

## Options

- `endpoint` (required): URL of the update API.
- `method` (optional): `GET`, `POST`, or `PUT`. The default is `POST`.
- `body` (optional): `query`, `form`, or `json`. The default is `form`, or
  `query` when `method` is `GET`.
- `params` (required): request fields.
- `timeout` (optional): request timeout. The default is `30s`.
- `result` (optional): response conditions. All configured conditions must
  match.
  - `success_code`: exact HTTP status code, or `2xx` (default) for any 2xx code.
  - `success_body`: text that must occur in the response body.
  - `success_body_regex`: `true` treats `success_body` as a regular expression.
    The default is `false`.

The module ID is `dns.providers.http_acme`.

This provider is intended for an ACME DNS challenge configuration. It
implements the libdns append and delete operations required by Caddy's ACME
solver, but not the complete set of operations required by Caddy's global DNS
provider configuration. Cleanup is a no-op because myaddr.tools expires ACME
challenge values automatically and does not document an API to delete one
value.
